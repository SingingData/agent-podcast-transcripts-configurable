# drawings

This folder contains the caricature drawings used by the agent in the emailed version of the transcript, along with the prompt materials used to create them.

The drawings in `caricature_drawings/` can be recreated by submitting the relevant prompt together with the original image from `prompts_to_get_caricatures/` to an image generation model.  Of course, you never get exactly the same image twice.  

In this case, these drawings were created with ChatGPT using GPT 5.4 with image generation enabled.

Note, the model had some trouble with the Brown and Batnick photo, and probably would do a better job with a different photo.
