# phrases-and-vocabulary

This folder contains reference lists used by the agent during transcript cleanup and formatting.

These files generally fall into a few categories:

- **Phrase lists used to identify the true start of the podcast**
  - for example, opening catch phrases, opening ad phrases, and closing ad phrases that help the agent decide where the real show begins and where ad copy ends
- **Lists of known speakers and hosts**
  - used to help the agent recognize which hosts are associated with each podcast
- **Lists of known transcription model mistakes to correct**
  - used to fix recurring speech-to-text errors and normalize names, terms, and show-specific vocabulary

In short, this folder holds the hand-maintained text references that help the agent make better transcript decisions.
